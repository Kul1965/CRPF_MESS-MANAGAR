How it works

  1. Add store items with base unit g, ml or pcs.
  2. Record purchases. The weighted-average rate updates automatically.
  3. Create each recipe for one serving and choose ingredients from Store.
  4. Plan a meal, select servings and attendees, send ration list to Cook, then confirm.
  5. Confirmed meal deducts stock and posts the calculated charge to selected members.
Prototype notice: this version saves in this browser only. It is structured for a later PHP/MySQL API, but it is not yet a shared online database. Do not use confidential personnel data until server login, permissions, backups and audit logs are implemented.
